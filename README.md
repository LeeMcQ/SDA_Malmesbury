# Malmesbury Praise

Praise & Worship songbook for **Malmesbury Seventh-day Adventist Church Women's Ministries**.

48 numbered hymns from the printed booklet — search, save, plan a Sabbath set, and present lyrics to the room.

## Songs

| Range | Collection |
| --- | --- |
| 1–29 | Numbered Praise & Worship |
| 30–48 | Additional Praise & Worship |

## Run locally

```bash
npm install
npm run dev
```

Then open the app at the printed local URL. Night reading, set lists, and saved songs stay in the browser.

## Stack

React 19, TanStack Start, Tailwind CSS v4.
